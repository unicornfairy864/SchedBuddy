# 03 · UI 规范

> 状态：生效　·　最近更新：v0.2.53（2026-09-05）　·　规范：`07-doc-standards.md`

风格关键词：**简洁、美观、清新**；浅色主题；所有可交互元素有反馈动画。界面语言简体中文。

## 1. 视觉基调

| Token | 值 | 用途 |
| --- | --- | --- |
| 背景 | `#F4F7FB` | 页面底色 |
| 卡片/表面 | `#FFFFFF` | 视图卡片、弹窗 |
| 主色 | `#3EAF9B`（清新青） | 主按钮、选中态、链接 |
| 空闲带 | `#E9F7F0` + 绿点纹 | 底部空闲 |
| 栅格线 | `#E7ECF3` / 整点加深 | 时间轴 |
| 文字 | `#1F2A37` / 次 `#6B7683` | 标题/正文 |
| 警告 | `#F5A623`；错误 `#E4574E` | 冲突/删除 |

类型默认色（创建时可改，可随机）：fixed `#E4574E`、specific `#4A90E2`、optional `#F5A623`、temporary `#9B7EDE`。

字体：系统栈 `-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。

## 2. 布局（周/日视图，核心为"横向条"）

- 时间轴**横向**，所有可见日共享同一水平刻度；**周视图自动裁掉 7 天共有的首/尾空余**（起点 = 全周最早日程前 1h，终点 = 全周最晚日程后 1h，全周无日程则 0:00–24:00），7 条日带同轴显示。
- 布局采用**横向日带**：每个可见日渲染为一条「日带」= 左侧星期/日期 gutter + 右侧横向时间区；日带内自下而上为排 0（最底排，未占用处画浅绿空闲带 + 各色方块）与上方叠加排，**排布自下而上按重要度贪心入排、同排可混合类型、永不产生空排**。
  - **周视图** = 7 条日带纵向堆叠，**日带高 = 行数 × 单位行高**（2 行=2 份、1 行/空日=1 份）并自动填满整个可视区；今天日带高亮 + “今天”徽标；
  - **日视图** = 按「上午 0:00–12:00」与「下午 12:00–24:00」拆成两条堆叠的半天带（每小时显示宽度翻倍）；**自动裁剪首尾空余**（首个日程前 1h ～ 末个日程后 1h，全天无日程时显示完整两半）；**跨 12 点的日程被拆在两带中，但视为同一整体**（同一 hoKey：hover/聚焦/动画在上下两段同步）。gutter 以 上午/下午 徽标区分。
- 字号整体加大（正文 15px、块内 12.5–14px、悬浮窗 13.5–15px）。
- **本机可编辑态**：每条日带 gutter 的「周几 / 上午下午」标签旁有**白底小圆 ＋ 新建按钮**（点击 → 新建弹窗，预填该日；空日带同样可新建）——新建入口在此，**顶栏不放新建**；只读端不渲染该按钮。
- 每条日带最底排（排 0）之下绘制**时间标尺**：每小时刻度短线 + 每 2 小时 HH:mm 文字。
- 块：圆角 10px；未 hover 时块内显示**名称**（字号 ≤12，居中，超长省略号）；每整点纵向细栅格线贯穿日带；今天的日带绘制「现在线」（细红线 + 圆点，每分钟刷新）。
- 未 hover 时方块**内部**显示名称（需求原文），hover 时名称行为不变但屏幕聚焦该块。

### Hover 聚焦 + 悬浮窗（关键交互）

- hover 某块 → 其余内容轻微压暗/缩放（CSS 类实现"聚焦"）；悬浮窗 120ms **快速淡入**于块上方（越界自动翻转到下方），微上浮 4px。
- 悬浮窗内容：`[颜色小方块] 名称` → 类型徽标(固定/社团/可选/临时) → 备注 → 时段（多段时**两行**：`当前：周一 08:00–09:30` 与 `其他：周三 10:00–11:30`）→ 规则摘要（如"单周 / 第1–16周 / 隔3天"）→ 单次例外数（如有）。
- **桌面（hover: hover && pointer: fine）悬浮窗可接住鼠标**：鼠标从块移入悬浮窗本体 → 窗口**保持显示**并现出「✎ 编辑」按钮（窗内可直接点编辑，无需先点击块）；移回方块 → 恢复浏览态（无按钮）；移向其它区域 / Esc / 点窗外 → 淡出。点击块（或**移动端点按**）仍可**固定**悬浮窗：固定态可交互（移向窗口不消失、Esc/点窗外/离开窗口取消固定），适合触摸设备。只读端无编辑按钮、点击不固定。

## 3. 创建/编辑弹窗

- 打开：各日带 gutter 的「＋」（周/日视图均可用，仅本机可编辑态）；已有块 → 悬浮窗「✎ 编辑」按钮（桌面：移入悬浮窗即现按钮；触摸：点按块固定后现按钮）。
- 由「＋」打开时预填该日：规则默认固定星期且 weekday=该日；默认时段 = 周视图/上午 09:00–10:00、日视图下午带 14:00–15:00（可在弹窗内任意修改，切一次性/隔N天也保留该日期）。
- 字段区：名称*、类型*（四选一带色点）、颜色*（色板 12 常用 + 取色器 + `#RRGGBB` 输入 + "随机"按钮）→ 见 4。
- **时段列表**（"类似列表的组件"，可增删行）：
  - weekly：每行 `[星期几 ▾] [开始] – [结束]`；
  - once：每行 `[日期] [开始] – [结束]`；
  - interval：起始日期 + 每 N 天 + 时段窗口行 `[开始]–[结束]`。
  - 时间用 `TimeField`：**时 : 分** 两段独立数字框，输满自动跳格，开始分满 → 结束时时满 → 下一行，形成整条连续输入流。
- **日期输入**（`DateField`，用于周锚点/隔N天起始/一次性日期/生效日期范围）：年·月·日三段独立数字框（各框仅容纳对应位数：年 4 位、月 2 位、日 2 位；输满自动跳格、回删跳回上一格），右侧日历按钮打开原生日期选择器；新建时若月/日被清空，输入满年份后自动补为**所点当天**的月/日；日期范围「起点日输满」自动跳到「终点年」。
- 规则区：单双周（无/单周/双周 + 学期起点日期，未设置提示；单双周为**自绘下拉组件**：白底细边触发钮 + 箭头，展开列表自带样式与选中高亮）、备注。
- **生效限制二选一**（「高级」区内，另有「不限制」档）：**日期范围**（起止 DateField：清除 / 起止颠倒校验，起点日输满自动跳终点年）或 **课程总数量**（"共 N 天"数字框；按天计次、同日多时段按 1 天；设定后展开到第 N 天截止，落库字段 `occurrenceLimit`）；切换即清空另一方。
- **「高级」折叠区**：单双周（仅固定星期）与生效限制收纳其中，默认收起（箭头旋转 + 高度过渡）；编辑且已设置相关项时自动展开。
- 保存按钮：**红/黄冲突仅提示、不阻止保存**（红 = 硬冲突/校验/服务端驳回，黄 = 警告；红存在时点击保存自动带 force 允许重叠落库），仅字段级校验问题（如空名称、时间非法、起止颠倒）会禁用保存。提醒统一显示在「高级」区之前。
- 动画：遮罩淡入 150ms + 面板 200ms 弹性放大（scale .96→1）；字段校验错误行抖动 240ms。

## 4. 颜色选择弹窗（嵌于表单）

常用色板 12 色（含四类型默认色）→ 原生取色器 → 手动 `#RRGGBB` 输入（实时校验/实时预览）→ "随机"（生成鲜明随机色）。选中色在名称旁同步显示为小圆点。

## 5. 反馈动画清单（统一节奏，180–240ms，缓动 `cubic-bezier(.2,.8,.2,1)`）

| 元素 | 反馈 |
| --- | --- |
| 按钮（主/次/图标） | hover 上浮 1px+加深；按下 scale .96；点击波纹(可选) |
| 视图切换（周/日 pill） | 滑块过渡 200ms |
| 删除 | 二次确认弹窗；确认后块向左"塌缩消失" |
| 新建保存 | 新块 300ms 从时间点淡入展开 |
| 冲突 | 对应行黄/红底淡入 + 抖动 |
| Snackbar | 底部滑入/滑出 |
| 加载/空态 | 骨架屏淡入；空态插画文字 |
| 滚动 | 惯性滚动，块 hover 不闪烁 |

## 6. 只读模式（LAN 浏览器）

`meta.readOnly=true` 时：隐藏新建/编辑/删除入口；hover 悬浮窗保留；页脚显示"只读 · 请在本机桌面端编辑"。顶栏右侧在只读模式下仅显示「只读」徽标，`⚙ 设置` 与各日带「＋」等写入口一律不渲染。

## 7. 顶栏（导航区，v0.2.23 重构 · v0.2.24 响应式 · v0.2.36 精简右区）

- **单行一体分区**（>900px 全展开）：左 = 品牌（Logo + `SchedBuddy`，版本号 `v0.x.y` 平文置于其名**下方**、字号稍小，不加粗不设标签底，无中文副题）→ 紧跟 **周/日切换** → 中 = 日期导航（`‹` `今天` `›` + 日期范围）→ 右 = 操作区。
- 右操作区两态（v0.2.36 起，`＋ 新建` 与 `⋯` 折叠菜单已移除——新建统一走各日带 gutter「＋」，见 §2/§3）：
  - 只读（LAN）→ 仅「只读」徽标；
  - 本机 → `⚙ 设置`（icon 按钮，各断点档常驻显示）。
- **响应式档位**（断点体系见 `06-dev-conventions.md` §5）：
  - `>900px`：单行全展开（现状）；
  - `≤900px`：紧凑单行（Logo/字号/间距/按钮收小）；
  - `≤720px`：双行网格（方案 3-B）—— 第 1 行 = 品牌｜周/日切换（**居中**）｜右区；第 2 行 = 日期导航居中；两行共享页面中轴线；品牌字号 ≤430px/≤360px 渐进收缩避让（不隐藏文字）；
  - `≤480px`：尺寸继续微调（Logo/按钮/字号收小）；
  - `≤430px`：空间不足时先省略日期段（`08/31 – 09/06`），**第N周常驻**；无周次时日期段回退显示；
  - `<300px`：极窄 —— 品牌仅保留 Logo（隐藏 `SchedBuddy` 与版本号小字）；
  - 板面日带内容断点仍为 `860px`（gutter 收窄，日带「＋」同步微缩）。
- Snackbar 轻提示：底部居中滑入/滑出（见 §5 动画清单），用于操作反馈与占位提示。
- 所有按钮反馈动效遵循 §5（hover 上浮/按下缩放等）。
